# Prompt Engineering 实战指南

Prompt Engineering 是与大语言模型高效沟通的艺术和科学。以下是真正有效的技巧。

## 1. 明确具体

模糊的 prompt 只会得到模糊的结果。不要说「写点关于 AI 的东西」，而是：

> 写一篇 500 字的博客文章，解释 Transformer 注意力机制的工作原理，面向没有 ML 背景的软件工程师。使用餐厅类比。

## 2. 善用 System Prompt

System prompt 设定上下文和角色：

```
你是一位资深 ML 工程师，正在做代码审查。
关注：正确性、性能、可读性。
格式：带严重等级的条目列表。
```

## 3. 思维链（Chain of Thought）

面对复杂推理，让模型一步步思考：

```
请一步步解决这个问题：
1. 首先，确定关键变量
2. 然后，建立方程
3. 最后，求解并验证
```

## 4. Few-Shot 示例

提供你想要的输出示例：

```
输入：这个菜太好吃了
情感：正面

输入：服务太差了，再也不来了
情感：负面

输入：还行吧，没什么特别的
情感：
```

## 5. 迭代优化

不要期望第一次就完美。根据输出结果不断调整你的 prompt。

## 核心要点

最好的 prompt 是清晰的、具体的，并且提供了足够的上下文让模型理解你的意图。
