# Hello World

欢迎来到我的新博客! 这个网站完全用 **纯 HTML, CSS 和 JavaScript** 构建, 不需要构建工具, 不需要框架。

## 特性

- **Markdown 驱动** - 用 `.md` 文件写文章, 通过 [marked.js](https://marked.js.org/) 渲染
- **中英双语** - 支持中文和英文切换
- **简洁设计** - 灵感来自学术个人主页
- **易于更新** - 只需添加 markdown 文件并更新 `posts/index.json`

## 如何添加新文章

1. 在 `posts/` 目录下创建 markdown 文件
2. 在 `posts/index.json` 中添加条目
3. 推送到 GitHub, 完成!
